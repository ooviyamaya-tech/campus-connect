# CampusConnect

A full-stack campus community dashboard for students, clubs, faculty, and administrators.

## Run locally

Prerequisite: Node.js 20+

```bash
npm install
npm run dev
```

The frontend runs at `http://localhost:5173` and the API at `http://localhost:4000`.

## Structure

- `frontend`: React + Vite + TypeScript dashboard
- `backend`: Node.js + Express + TypeScript API scaffold
